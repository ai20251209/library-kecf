# 🌟 별빛 북스페이스 (Starry BookSpace) - AI 스마트 작은도서관 LMS

초등학생과 중학생의 눈높이에 맞춘 **차세대 AI 독서 메이트 & 10,000권/3,000명 규모의 작은도서관 LMS(Library Management System)**입니다.

---

## ✨ 핵심 기능

1. **학생 맞춤형 AI 북버디 (BookBuddy)**
   - **3단계 눈높이 맞춤**: 초등 저학년(마법요정 퐁퐁이), 초등 고학년(탐험가 루카), 중학생(멘토 아테나)
   - **사고력 확장 심층 질문**: 등장인물 심리, 윤리적 선택, 시대 배경, 만약 내가 주인공이라면?
   - **독서 퀴즈 챌린지**: 3단계 내용 확인 퀴즈 및 축하 효과
   - **AI 독후감 코칭**: 학생이 작성한 리뷰에 대한 칭찬 및 생각거리 피드백

2. **게이미피케이션 독서 통장 (Reading Passbook)**
   - 책을 읽고 반납할 때마다 성장하는 **'독서 우주 나무'** (새싹 → 줄기 → 꽃 → 별빛 거목)
   - 독서 포인트, 레벨업, 도전 뱃지 수집 및 모바일 회원증 바코드

3. **작은도서관 사서 LMS (관리자 관제)**
   - **1초 초고속 바코드 대출/반납 터미널**
   - **AI 도서 메타데이터 자동 완성**: 도서명만 입력하면 줄거리, 청구기호, 권장학년, 퀴즈 자동 생성
   - **10,000권 도서 및 3,000명 회원 관리, CSV 일괄 내보내기/가져오기**

## 🚀 로컬 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저 접속
http://localhost:3000
```

## ☁️ 배포 가이드 (GitHub + Vercel + Supabase)

### 1. GitHub & Vercel 배포
1. 본 프로젝트 코드를 GitHub 저장소에 푸시합니다.
2. [Vercel](https://vercel.com)에 로그인 후 `Import Repository`를 진행합니다.
3. 환경변수에 `GEMINI_API_KEY`를 등록하면 자동 배포가 완료됩니다 (무료 Hobby 플랜으로 충분).

### 2. Supabase 클라우드 데이터베이스 연동 (선택)
1. [Supabase](https://supabase.com)에서 신규 프로젝트를 생성합니다.
2. `SQL Editor`에서 `src/supabase/schema.sql` 스크립트를 붙여넣고 실행하면 10,000권 도서, 3,000명 회원, 트리거 자동 연동이 준비됩니다.
